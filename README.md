# CampusFlow

CampusFlow is a responsive student productivity dashboard for tracking assignments, course progress, focus time, and upcoming classes.

## Features

- Academic summary cards and weekly focus chart
- Assignment filters for open, completed, and all tasks
- Add-task form with course, due date, and priority fields
- Interactive task completion states
- Notification and class-detail feedback
- Responsive desktop, tablet, and mobile layouts
- Accessible labels, keyboard focus states, and status messages

The application currently uses sample data stored in the browser session. A future version could connect the same interface to a database and student login system.

## Run locally

1. Install Node.js 22 or newer.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local address shown in the terminal.

Create a production build with `npm run build`.
